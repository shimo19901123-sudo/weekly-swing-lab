週間上昇率と金曜出来高は厳格に絞り込み、合格が5銘柄未満でも基準外銘柄は補充しません。価格帯別出来高は日足の高安値と出来高からの近似であり、取引所の約定価格別実測値ではありません。業種シグナルは資金の流れタブで確認できますが、銘柄スコアには自動加点しません。参考スコアは単なる独自ルールによる機械的な優先順位であり、勝率・期待収益を保証しません。決算日や信用残が未確認の場合は「要確認」とし、買い推奨にしません。

使い方

① 金曜の大引け後にランキング更新
GitHub Pagesで公開し、同梱のGitHub Actionsを有効にすると、平日大引け後に月曜始値・当該週の最新終値を取得し、金曜夜はランキングを更新します。7種類のMA・RSI・出来高倍率・価格帯別出来高（推計）はランキング基準日までの日足で計算します。取得に失敗した場合は旧データのままとし、確認日を表示します。
② 決算・信用残の確認
株の「分析・編集」で最新の決算予定、信用買残・売残と買残増減、機関空売り増減を入力。決算予定を公式IRで確認して「確認済」にチェック。保有予定週内に決算があれば自動で除外します。
③ 資金の流れで業種・テーマの5日指標を確認
33業種の当日指数ランキングは参考表示です。5日業種騰落率、同期間のTOPIX、売買代金倍率、値上がり銘柄比率を登録すると資金集中の兆候を評価します。独立した日次情報を週次ランキングと混同しないでください。
④ 5銘柄を選んで月曜・金曜の価格を記録
星マークで銘柄を選べます。月曜始値と当該週の最新終値（途中経過）を比較し、金曜の終値が取得された場合のみ金曜売却の結果とします。100株の損益を自動集計します。価格が未取得なら空欄です。

このアプリの自動化範囲

GitHub Actionsの実行環境から、金曜の週次ランキングと価格の取得、5/25/75/100/200/250/300日SMA、14日RSI、出来高比率、過去120営業日の日足高安値内に出来高を均等配分した価格帯別出来高の推計を試みます。推定出来高は実際の約定価格別出来高ではありません。取得元仕様・アクセス制限によって失敗する場合があります。決算予定の網羅確認・信用残・機関空売りは自動検証済みとはせず、手動確認が必要な段階です。アプリ単体をiPhoneのホーム画面に追加するにはGitHub PagesなどHTTPSサイトへの公開が必要です。
