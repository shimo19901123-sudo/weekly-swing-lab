# WEEKLY SWING LAB（試作）

週間上昇率ランキングを起点に、月曜寄付→金曜引けの現物100株スイングを検討する静的Webアプリです。**投資推奨・自動売買ではありません。**

## すぐ使う

`index.html` をPCブラウザで開いてください。2026-10-30の参考データが初期表示され、シミュレーション入力やCSV出力は利用できます。

## iPhone/iPadでアプリ風に利用する

1. GitHubで**新しい公開リポジトリ**を作成。既存のボートレース用リポジトリは変更しないでください。
2. このZIPを展開した中身（`.github/workflows/update.yml`も）を新しいリポジトリのルートにアップロード。
3. GitHubの Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 表示された `https://<アカウント>.github.io/<リポジトリ名>/` にSafariでアクセスして、共有 → ホーム画面に追加。
5. Settings → Actions → General → Workflow permissionsで書き込み権限を付ける必要がある場合があります。ワークフローを明示的に有効化してください。

## データ自動取得の範囲と制約

- GitHub Actionsは金曜20:20 JSTに週次ランキング取得を試行します。週間+5〜12%・金曜単日出来高1万株以上をハード条件にします。従来の株価250円以上・売買代金5000万円以上も維持します。成功した場合のみ `data.json` を上書きします。
- yfinanceを通じた株価からMA5/25/75/100/200/250/300、RSI14、出来高倍率、日足近似の価格帯別出来高を算出します。市場データの取得やライブラリ仕様によって失敗することがあります。
- 参考としてトレーダーズ・ウェブの決算カレンダーの一部を解析して、見つかった発表日を表示します。**予定日が出ないことは「決算なし」を意味しません。**
- 信用買残、売残、増減、機関空売り増減は、**現時点では自動連携未実装**です。JPXおよび機関投資家のあしあとで確認して、アプリ上で入力してください。
- 決算日を会社IRなどで確認した日付を明記しない限り「条件確認済」に変わりません。
- 価格帯別出来高は直近最大120営業日の日足高値〜安値に日々の出来高を均等配分した参考推計で、約定した価格帯の実出来高とは異なります。高密集帯を支持・抵抗と断定できません。
- 300日移動平均には300営業日以上の日足履歴が必要です。足りない銘柄は未取得のままにします。
- 金曜のランキング上位を無条件に買う設計ではありません。未確認データによる見かけのスコア上昇を防ぐため、「条件確認済」と「要確認」を分けます。
- 月曜始値・金曜終値は、両日が実際に取引日のときのみ自動取得します（取得失敗時は入力）。祝日を火曜にずらしません。
- ブラウザのローカル保存を使うため、入力した分析メモは端末間で同期されません。週ごとに別々に保存します。データJSONはインポート/エクスポートできますが、端末内メモは含みません。
- Actionsの定刻起動はGitHub側の負荷で遅延・不実行となる場合があります。データは時刻と状態を見て確認してください。

## 計算

`購入資金 = 月曜始値 × 株数`、`売却額 = 金曜終値 × 株数`、`損益 = 売却額 - 購入資金 - 往復手数料`。税金、値幅制限、板厚、スリッページ、配当、約定できなかった場合の損益は反映しません。1銘柄100株が既定値です。

## v5（2026-11-03）業種別・テーマ別「資金の流れ」タブ

- アプリに「資金の流れ」タブを新設しました。東証33業種の2026-11-02大引け時点の**前日比騰落率**を参考表示します。出典： https://s.kabutan.jp/warnings/sector_stocks_ranking/daily_charts 。**日次スナップショットであり、最新相場に自動更新されません**。株価騰落を資金の純流入と取り違えないでください。
- テーマ別（AI・半導体／データセンター／電線・光ファイバー／防衛など）は別タブ内プルダウンで確認できますが、テーマそのものは東証33業種の公式分類ではありません。初期データは空欄です。
- 直近5日間の業種騰落率・同期間TOPIX騰落率・直近5日平均売買代金・その前20日平均売買代金・直近5日上昇銘柄比率を**同一対象・同一期間・同一単位で**入力すると、参考スコアと「資金集中の兆候」を判定します。判定は独自ヒューリスティックで、客観的な純流入額、運用成果、株価上昇を保証しません。
- 3指標が全て揃うことが必須。強判定：対TOPIX+2.0ポイント以上、直近5日平均売買代金/直前20日平均1.30倍以上、上昇銘柄比率60%以上。中判定：各+1.0pt/1.10倍/55%以上。データ不足は**未判定**。
- 5日データは入力端末のブラウザローカル保存。JSONエクスポートとインポートに対応。既存の100株損益シミュレーション、5銘柄選定、決算・信用残・MA200、既存アイコンは維持しています。銘柄編集で業種・テーマを選び、業種と個別銘柄を関連付けられます。
- 業種分類の自動付与、セクターデータの毎日自動更新、テーマ別売買代金の自動集計、取引主体別の資金純流入推計は**未実装**です。金曜のChatGPT定期レポート側には業種・テーマの調査項目を追加済み（アプリへの自動書き込みとは別機能）。
- 2026-11-03は現物株式の休業日です。最新の業種情報は必ず表示日付と出典を照合してください。

## v6（2026-11-04）週間上昇率の説明・月曜始値／最新終値

- ランキングの `gainPct` は **トレーダーズ・ウェブ掲載の前週末比** で、当該週の月曜始値からのリターンではありません。サイトから取得した数字をそのまま保存し、月曜寄付後の価格変化とは必ず区別します。
- 候補カードと個別銘柄分析画面に「対象週の月曜始値」「取得できた最新営業日の終値と取得日」「月曜始値比」「100株参考損益（手数料・税前）」を追加しました。
- 11月3日のような休場日の場合は、最後にデータが取得できた日付を表示します。祝日の月曜始値は代替日を推測せず空欄を維持します。
- 金曜大引けより前は **途中評価** と表示し、金曜の終値が実際に確認できて初めて「金曜終値での計算」とします。取得できなかった価格や、売買の約定可否は補完しません。100株シミュレーションの前提（手数料・税金等）は従来どおりです。
- 新しい `daily_prices.py` はランキング基準日までの日足から MA5/25/75/100/200/250/300、RSI14、出来高倍率、価格帯別出来高（日足近似）を計算し、対象週が始まったら月曜始値と直近終値を取得します。ランキング基準日が古いままでも、基準日の指標と当該週の日次価格を区別して保存します。
- `.github/workflows/update.yml` を更新しました。**平日17:45頃（JST）に日次価格、金曜20:20頃（JST）にランキングを更新する試行**をします。GitHub Actionsは実行遅延・失敗・データ取得制限があり、実際の取得成功は Actions のログと `data.json` の `quotesCheckedAt` / `latestCloseDate` を確認する必要があります。外部データの取得・実運用の動作確認は未実施です。
- 公開サイトは作り替えたHTMLだけでは日次データを取得できません。**必ず `daily_prices.py` と `.github/workflows/update.yml` もGitHubにアップロード**してください。iPhoneのファイルアプリでは `.github` のようなドット始まりのフォルダが表示されにくい場合があります。
- 以前の週次候補、選定条件、信用需給と決算の要確認判定、業種別タブ、ホーム画面アイコン、既存のブラウザメモは保持しました。
- 日足は非公式 `yfinance`（Yahoo Finance由来）を利用します。取得できない場合があり、利用条件・データ転載制限にも注意してください。公に価格データを配信する場合は、適切な利用許諾があるデータプロバイダーへの移行を推奨します。API認証キー・秘密情報を公開リポジトリやHTML内に記載しないでください。
